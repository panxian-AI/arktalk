# ArkTalk —— 两台设备直连聊天，数据只留在本机

ArkTalk 是一套独立的 P2P 聊天软件：**不需要注册、不经过任何第三方服务器**，
消息在两台设备之间直接传输，聊天记录、联系人全部保存在各自设备上。

- **电脑端**：Windows 免安装版，解压双击 `ArkTalk.exe` 即用
- **手机端**：安卓 APK，直接安装

```
设备 A（ArkTalk）←──── P2P 直连（局域网 / OpenP2P 穿透）────→ 设备 B（ArkTalk）
     │                                                        │
 本机界面 127.0.0.1:3020                               本机界面 127.0.0.1:3020
 P2P 服务 0.0.0.0:3021                                 P2P 服务 0.0.0.0:3021
```

---

## 一、快速开始

### 电脑端（Windows）

1. 解压 `ArkTalk-x.x.x-win64.zip` 到任意目录
2. 双击 **ArkTalk.exe**（窗口可关闭到系统托盘，消息继续接收）
3. 点左下角头像 →「我的账号」，设置昵称/头像，并记住你的**账号 ID**（一串数字）

### 手机端（Android）

1. 安装 `arktalk-x.x.x-release.apk`（首次启动会请求通知/麦克风权限，都允许）
2. 设置昵称/头像，记住**账号 ID**
3. 如果你的手机卡是物联网卡/广电卡（DNS 被拦），按提示开启「DNS 修复」一次即可

## 二、两台设备怎么聊起来（核心一步）

1. **互加联系人**：联系人页右上角「＋」，填对方的三样信息：
   - 对方**账号 ID**（数字）
   - 备注（随意）
   - **连接地址** `对方的IP:3021`
     - 同一局域网：填对方内网 IP（如 `192.168.1.5:3021`）
     - 跨网络：填穿透地址（见下一节），或 `127.0.0.1:13100`（本机走穿透隧道时）
2. **两边都要加**（联系人必须双向手动添加，陌生账号的消息一律忽略）
3. 任一方发消息即自动建立直连；对方离线时消息进**发件箱排队**，对方上线自动补发

### 跨网络怎么连（OpenP2P 穿透）

不同 WiFi/不同城市也能聊，靠内置的 OpenP2P 穿透：

1. 两台设备用**同一个** OpenP2P 账号的令牌：到 openp2p.cn 注册后拿到 Token
2. 「我的账号」→ 填入 OpenP2P 令牌（两端填同一个）
3. 每台设备自动注册节点 `arktalk-<账号ID>`，隧道在本机映射为 `127.0.0.1:13100 → 对方:3021`
4. 对方的连接地址填 `127.0.0.1:13100` 即可（两端互填）

> 同一个令牌必须两端一致；节点名自动带账号 ID，不会冲突。

## 三、功能一览

| 功能 | 怎么用 |
|---|---|
| 私聊 / 群聊 | 群聊先建群（勾选成员），消息逐成员直发 |
| 图片 | 输入栏 🖼️；开「原图」开关发不压缩的原图（超限自动转压缩） |
| 图片放大 / 保存 | 点聊天里的图片全屏看；灯箱内「保存图片」「打开位置」 |
| 文件 | 输入栏 📎；只发卡片，**对方点「保存」才开始传输**；下过再进会话显示「已保存：路径」和「📁 位置」按钮，不会重复下载 |
| 打开位置 | 文件卡片「📁 位置」：电脑打开资源管理器并选中文件；手机打开系统「下载」应用 |
| 已读 / 未读 | 自己发的消息气泡下角标「已读/未读」，对方打开会话即变已读 |
| 撤回 | 对方离线时排队中的消息旁有红色「撤回」按钮；一旦发出即不可撤 |
| 引用回复 | 消息旁「引用」按钮 |
| 语音消息 | 🎤 点一下录音，再点发送，最长 60 秒 |
| 后台通知 | 手机端锁屏/切后台收到消息弹通知，点击直达会话 |
| 托盘 | 电脑端关窗收进托盘继续收消息；托盘菜单可「重启 ArkTalk」 |
| 存储位置 | 电脑端「我的账号」里可改聊天记录/文件目录，改后自动迁移并重启 |

**稳定性**（无需操心，自动处理）：

- 半开连接自愈：12 秒探测、40 秒无响应自动清理重连
- 断线重连后自动补拉当前会话消息、重发已读回执
- 文件传输分块 1MB、10 路并发、乱序重排、丢块自动重传、落盘前校验
- 手机端选文件走原生通道：系统选择器把页面盖住/重建都不影响发送

## 四、数据在哪、怎么备份

所有数据在本机，拷走即备份：

| 内容 | 位置 |
|---|---|
| 账号 / 联系人 / 群 | `data/contacts.json` |
| 聊天记录 | `data/messages/<chatKey>.jsonl` |
| 我发出的文件 | `data/files/` |
| 收到的文件 | 电脑：`下载\ArkTalk\`；手机：系统「下载/ArkTalk/」（相册可见） |

### 修改存储位置（电脑端）

「我的账号」→「存储位置」里可以改两个目录：

- **数据目录**：聊天记录、联系人、我发出的文件缓存（默认是应用目录下的 `data/`）
- **接收文件目录**：对方发来的文件保存到哪（默认是 `下载\ArkTalk\`）

点「更改数据目录…」或「更改接收目录…」，选一个文件夹并确认。程序会把已有数据**复制**到新目录（原目录保留、不删除），然后自动重启生效；改完在同一处能看到新的实际路径。

**发行包是脱敏的**：安装包内不含任何账号、令牌、聊天数据——拿到的人装上就是全新账号。

## 五、遇到问题

| 现象 | 处理 |
|---|---|
| 电脑端界面卡住 / 收不到消息 | 托盘右键 →「重启 ArkTalk」（界面有自动重连，一般几秒自愈） |
| 想确认连接质量 | 浏览器开 `http://127.0.0.1:3020/api/links`，看每条连接的 `silentMs`（>20000 说明链路哑了） |
| 手机跨网不通（物联网卡等） | 开启「DNS 修复」（VPN 授权一次）；两端确认 OpenP2P 令牌一致 |
| 一端在线一端离线 | 升级到最新版（半开检测已内置）；仍不行用 /api/links 定位 |
| 导出诊断包 | 「我的账号」→ 导出诊断包（不含令牌明文与聊天内容） |

## 六、开发者

```bash
npm install
npm run app        # 桌面窗口（Electron）
npm start          # 浏览器模式，手动开 http://127.0.0.1:3020
npm run selftest   # 自检 22 项（双实例互通 + 文件传输回归）
npm run package:win  # 打包 Windows 免安装版（自动脱敏 + 令牌/账号 ID 扫描）
```

- 协议：WS 直连 + 自研 PeerLink（多路竞速拨号、地址健康度、离线发件箱、消息去重）
- 测试：`test/selftest.js`、`test/file-e2e.mjs`、`test/nat-race.mjs`、`test/read-recall.test.mjs`
- 安卓工程：`../arktalk-android`（Gradle `assembleRelease`，前端由 `syncUi` 任务自动从 `public/` 同步）

## 边界与声明

- 与 QQ / 腾讯无任何数据沟通；不含 AI
- 界面服务只绑 127.0.0.1；P2P 内核绑 0.0.0.0:3021（接受对方设备直连所必需）
- 跨公网传输依赖 OpenP2P 隧道加密；端到端消息加密在路线图中
